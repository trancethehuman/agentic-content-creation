# Skills

One folder per content type. Each skill has a `SKILL.md` (the how-to, with frontmatter so agents can discover it) and any tools it needs.

| Skill | Makes | Output |
|---|---|---|
| [infographic](infographic/SKILL.md) | Infographics, social posts, posters, cheat sheets | PNG, 1080×1350 |
| [animated-video](animated-video/SKILL.md) | Calm, minimalist explainer videos and reels | MP4, 1080×1440 |

More to come (carousels, Reels at 9:16, thumbnails, …).
